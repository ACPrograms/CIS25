# Week 8 - Final Project

## Module 8: Bank Account Simulation
This project simulates a simple bank account system using C++ Classes and File I/O.

### Files Included:
1. **bank_account.cpp**: The main source code.
2. **transactions.txt**: The log file generated by the program (automatically created when code runs).
3. **screenshots.pdf**: Visual proof of the program execution and file output.

### Features:
- **Class Design:** Uses a `BankAccount` class with private data members for security.
- **Transactions:** Allows users to Deposit funds and Make Purchases.
- **Logic:** Prevents purchases if the balance is insufficient.
- **File Persistence:** Every valid transaction is appended to `transactions.txt` using `ofstream` in append mode (`ios::app`).
